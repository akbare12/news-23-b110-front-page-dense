## How it works

`draw.py` (Pillow) renders `entry.png` (1024×1024). `main.py` (stdlib only — it parses the PNG header by hand with `struct`) validates the image and copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`.

```sh
python3 draw.py          # render entry.png
MAKEFUN_OUTPUT_DIR=out python3 main.py   # validate + copy to out/entry.png
```
